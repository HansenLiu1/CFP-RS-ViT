# Figures 3--7

The quantitative figures are generated with matplotlib from the compact CSVs
in `data/`.  They do not need feature caches, raw imagery or a GPU.

| Script | Output | Inputs |
|---|---|---|
| `fig3_specificity.py` | Figure 3 | `data/fig3_specificity.csv` |
| `fig4_geometry_transfer.py` | Figure 4 | `data/fig4_geometry.csv`, `data/fig4_transfer.csv` |
| `fig5_layerwise.py` | Figure 5 | `data/fig5_dataset.csv`, `data/fig5_fair1m.csv` |
| `fig6_common_alignment.py` | Figure 6 | `data/fig6_common.csv`, `data/fig6_alignment.csv`, `data/fig6_alignment_pairs.csv` |
| `fig7_readout.py` | Figure 7 | `data/fig7_dose.csv`, `data/fig7_layerwise.csv`, `data/fig7_layerwise_diff.csv` |

Run all five from the repository root:

```bash
python figures/fig3_specificity.py
python figures/fig4_geometry_transfer.py
python figures/fig5_layerwise.py
python figures/fig6_common_alignment.py
python figures/fig7_readout.py
```

Outputs are written to `figures/output/` as vector PDF plus a 600 dpi PNG.

## Builders

`build_data.py` and `build_fig5_data.py` are provenance builders.  They need
the frozen paper export or feature caches and are not required for the Tier 1
paper audit.

```bash
python figures/build_data.py --export /path/to/paper-export
python figures/build_fig5_data.py \
    --run-root /path/to/runs \
    --runs 1729=cfp-1729,2718=cfp-2718,3141=cfp-3141
```

`build_fig5_data.py` re-fits layerwise M1 from the feature artifacts through
`cfra.directions`.  The committed `fig5_*.csv` files remain the authoritative
plotting inputs for the paper audit.

The Figure 6 builder is intentionally not shipped: the current version consumes
an internal Exp2 output.  Figure 6 is regenerated from the `layerwise` task once
that task is ported; the committed `fig6_*.csv` files are the frozen inputs.

## Conceptual figures

Figures 1--2 are not generated by these scripts.  They are conceptual SVG/PNG
assets.  Their source labels and raster panels are being cleaned up separately;
the final PNGs in `output/` are the paper versions.  Do not treat a different
SVG renderer as a numerical reproducibility check.

## Fonts and size

Figures 3--7 use Times New Roman with STIX/DejaVu fallbacks, a 3.5 in column
width, and exact-size output (no tight bounding box).  If Times New Roman is
not installed, matplotlib falls back; this changes glyph metrics but not the
data.
